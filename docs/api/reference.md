# API 参考

## Charts

| 组件 | 说明 |
|------|------|
| BarChart3D | 3D 柱状图 |
| PieChart3D | 3D 饼图/环形图 |
| LineChart3D | 3D 折线图 |
| ScatterChart3D | 3D 散点图 |
| SurfaceChart3D | 3D 曲面图 |
| HeatmapChart3D | 3D 热力图 |
| RadarChart3D | 3D 雷达图 |
| FunnelChart3D | 3D 漏斗图 |
| ForceGraph3D | 3D 关系图 |
| GlobeChart3D | 3D 地球图 |
| FlipCardTable3D | 翻转卡片表 |
| FloatPanelTable3D | 悬浮面板表 |

## Map

| API | 说明 |
|-----|------|
| Map3D | 3D 地图主类 |
| wgs84ToGcj02 | 坐标转换 |
| haversineDistance | 球面距离 |
| pointInPolygon | 围栏判断 |
| bufferPoint | 缓冲区 |
| TrackPlayer | 轨迹回放 |
